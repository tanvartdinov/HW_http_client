# Афиша — учебный сервис на FastAPI

Красивый каталог вымышленных мероприятий для практики HTTP, requests, проверки JSON и статического скрапинга с BeautifulSoup. 36 событий: по двенадцать концерта, спектакля и выставки. Данные фиксированы на май 2027 года: результаты упражнений не меняются со временем. Все площадки, адреса и события вымышлены; билеты не продаются.

## 1. Запуск

Нужен Python 3.11 или новее (рекомендуется 3.12). Установите его с https://www.python.org/downloads/. На Windows при установке включите Add Python to PATH. Распакуйте архив, откройте терминал в папке `afisha`, где находятся `requirements.txt` и этот файл. Интернет необходим для установки зависимостей.

### Windows (PowerShell или cmd)

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --reload
```

Активация окружения не требуется: команды явно используют Python из `.venv`. На Ubuntu/Debian при ошибке создания окружения установите пакет `python3-venv` через системный менеджер пакетов.

Оставьте терминал открытым, дождитесь сообщения `Application startup complete`, затем откройте:

- Афиша: http://127.0.0.1:8000/
- Карточка мероприятия: http://127.0.0.1:8000/events/1
- JSON API: http://127.0.0.1:8000/api/v1/events
- Интерактивная документация: http://127.0.0.1:8000/docs
- OpenAPI JSON: http://127.0.0.1:8000/openapi.json

Остановка: Ctrl+C. Для повторного запуска достаточно последней команды. Если порт занят, добавьте `--port 8001` и замените порт в адресах. Если появляется `No module named app`, проверьте текущую папку: внутри неё должна быть папка `app`. Если нет модуля `uvicorn`, установите зависимости тем же Python из `.venv`.

Сам сайт работает без внешних шрифтов, картинок, JavaScript и подключения к интернету. Интерфейс `/docs` загружает Swagger UI с CDN и требует интернета; `/openapi.json` доступен локально. База данных, Docker и ключи доступа не нужны.

## 2. Возможности сайта

Поиск по подстроке названия без учёта регистра, фильтр категории, совместное использование фильтров, отдельные страницы мероприятий, пустая выдача и страница 404. Дизайн адаптируется к телефону. HTML полностью формируется сервером: данные доступны сразу в `response.text` и не требуют Selenium или Playwright.

## 3. Контракт API

Базовый URL: `http://127.0.0.1:8000`. Авторизация не требуется. Формат ответа: `application/json`. Тело GET-запросов отсутствует.

### GET /api/v1/events

| Query-параметр | Тип | Обязателен | Правило |
| --- | --- | --- | --- |
| q | string | Нет | До 100 символов. Подстрока названия, регистр игнорируется, пробелы по краям удаляются. Пустая строка — все названия |
| category | string | Нет | `concert`, `theatre` или `exhibition`. Если параметр отсутствует — все категории |

Оба фильтра объединяются условием И. Порядок соответствует исходному файлу данных, пагинации нет. Пример: `/api/v1/events?q=джаз&category=concert`.

Успех: HTTP 200, объект с обязательными полями `items` (массив объектов Event) и `total` (целое, равно длине items). Если совпадений нет, ответ также 200:

```json
{"items": [], "total": 0}
```

### GET /api/v1/events/{event_id}

`event_id` — целочисленный идентификатор. Успех: HTTP 200 и один объект Event, без обёртки items/total. Несуществующий ID: HTTP 404 и `{"detail":"Мероприятие не найдено"}`. Некорректный ID (например, `abc`), неизвестная категория или слишком длинный q: HTTP 422 с массивом ошибок в поле `detail`. Пустой `category=` тоже не является допустимой категорией: для всех категорий параметр нужно убрать.

### Объект Event

Все перечисленные поля обязательны и не равны null.

| Поле | Тип JSON | Значение |
| --- | --- | --- |
| id | integer | Идентификатор |
| title | string | Название |
| category | string | concert / theatre / exhibition |
| starts_at | string | Дата и время ISO 8601 с часовым смещением, например `2027-05-14T20:00:00+03:00` |
| venue | string | Площадка |
| address | string | Адрес |
| price | integer | Стоимость в рублях; 0 означает бесплатно |
| currency | string | RUB |
| organizer | string | Участники или организатор |
| description | string | Описание; абзацы разделены двумя переводами строки |
| age_limit | string | Возрастная маркировка |
| url | string | Относительная ссылка на HTML-страницу, например `/events/1` |
| theme | string | Цветовая тема постера |
| poster_title | string | Надпись на постере |
| poster_subtitle | string | Подзаголовок постера |

Пример первого запроса (в отдельном Python-файле):

```python
import requests

response = requests.get(
    'http://127.0.0.1:8000/api/v1/events',
    params={'q': 'джаз', 'category': 'concert'},
    timeout=5,
)
response.raise_for_status()
data = response.json()
print(data['total'])  # 3
for event in data['items']:
    print(event['title'], event['starts_at'])
```

Запускайте свои скрипты Python из созданного окружения. `requests` и `beautifulsoup4` уже включены в зависимости.

## 4. Практика BeautifulSoup

HTML-поиск использует те же параметры: `/?q=джаз&category=concert`. Маршруты HTML и API используют один источник данных и одну функцию фильтрации.

| Что найти | CSS-селектор | Как получить |
| --- | --- | --- |
| Карточки в каталоге | `.event-card` | `select()` |
| Название и ссылка внутри карточки | `.event-title a` | `.get_text(' ', strip=True)`, `['href']` |
| Дата и время | `time.event-date` | атрибут `datetime` |
| Площадка | `.event-venue` | текст |
| Цена | `.event-price` | атрибут `data-value`, затем int() |
| Заголовок на странице события | `h1.event-title` | текст |
| Адрес | `.event-address` | текст |
| Организатор | `.event-organizer` | текст |
| Описание | `.event-description` | `.get_text('\n\n', strip=True)` |

Стрелка в заголовке каталога декоративная (`span[aria-hidden]`): удалите её перед извлечением текста или получите точное название на странице мероприятия. Ссылки относительные: используйте `urllib.parse.urljoin`. Не извлекайте дату и цену из визуальной подписи — для практики предусмотрены машинно-читаемые атрибуты.

Упражнения:

1. Получить список мероприятий через requests и вывести total.
2. Найти «ДЖАЗ», проверить поиск с пробелами по краям и пустую выдачу.
3. Создать API-клиент с requests.Session, тайм-аутами и обработкой HTTP-ошибок.
4. Проверить типы и обязательные поля JSON вручную или с Pydantic.
5. Получить HTML главной страницы, собрать ссылки через BeautifulSoup. Отработать `find`, `find_all`, `select`, `select_one`.
6. Перейти по ссылкам и собрать название, время, площадку, организатора, описание, цену и абсолютную ссылку. Делать паузу между запросами.
7. Сохранить результат в UTF-8 JSON (`ensure_ascii=False`, `indent=2`). Сравнить данные HTML с API.
8. Проверить бесплатное событие (id=5): цена 0 — это значение, а не отсутствие данных.

## 5. Учебные ошибки

Специальные маршруты отделены от основного каталога. Они нужны для повторяемых упражнений, а не имитируют случайные сбои.

| Маршрут | Результат | Что проверить |
| --- | --- | --- |
| /demo/500 | Всегда HTTP 500 | raise_for_status(), ограниченные повторы |
| /demo/timeout?seconds=5 | Ответ 200 через 5 секунд | requests.get(..., timeout=1) вызывает Timeout |
| /demo/rate-limited | Всегда 429, Retry-After: 2 | Обработка ограничения; повторы должны иметь предел |
| /demo/broken-json | HTTP 200, Content-Type JSON, синтаксически повреждённое тело | Ошибка response.json() |
| /demo/bad-schema | HTTP 200, корректный JSON неверной структуры | Валидация контракта |
| /api/v1/events/999 | HTTP 404 | Несуществующий ресурс |
| /api/v1/events?category=unknown | HTTP 422 | Ошибка параметров |

`raise_for_status()` проверяет HTTP-ошибки, но не синтаксис JSON и не контракт. `seconds` допускает значения от 0 до 30. Маршрут 429 не становится успешным после ожидания — это намеренно постоянный учебный ответ.

## 6. Структура и изменение данных

- `app/main.py` — FastAPI, модели, фильтрация, HTML/API и учебные ошибки.
- `app/data/events.json` — единственный источник данных для сайта и API.
- `app/templates/` — Jinja2-шаблоны страниц.
- `app/static/style.css` — адаптивный дизайн и типографические постеры.
- `requirements.txt` — зависимости.

После изменения JSON перезапустите сервер: данные читаются при импорте приложения. Для нового события используйте уникальный id, правильный url `/events/ID`, категорию из списка и ISO-дату с часовым смещением. Постеры используют темы blue/orange/pink/purple/green/yellow. Герой на главной посвящён маю 2027; при переносе дат измените его подпись в `index.html`.

Локальный учебный сайт предназначен для свободного сбора данных в рамках этой практики. Это разрешение не распространяется на сторонние сайты.

Документация FastAPI: https://fastapi.tiangolo.com/ — шаблоны: https://fastapi.tiangolo.com/advanced/templates/.
