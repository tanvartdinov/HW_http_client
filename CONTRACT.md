# Контракт учебного API

Базовый URL: http://127.0.0.1:8000. GET без тела, авторизация не требуется, ответы API — application/json. Это спецификация для проверки клиентом; дополнительные неизвестные поля разрешены. Данные учебные и фиксированы.

## Список

`GET /api/v1/events?q=джаз&category=concert`

| Параметр | Обязателен | Правила |
| --- | --- | --- |
| q | Нет | Строка, максимум 100 символов. Поиск подстроки title без регистра, пробелы по краям удаляются. Пустая строка соответствует всем названиям |
| category | Нет | Только concert / theatre / exhibition. Для всех категорий параметр нужно убрать; пустое значение недопустимо |

Фильтры объединяются через И. Пагинации нет. Порядок записей соответствует файлу данных, сортировку API не гарантирует как отдельную функцию. Ответ 200: объект `items` (массив Event), `total` (целое >= 0, строго равно длине items). Пустой результат: `{"items": [], "total": 0}` с HTTP 200. ID внутри массива уникальны.

## Одно событие

`GET /api/v1/events/{event_id}`. event_id — целое. 200 возвращает непосредственно Event, без обёртки items/total. Несуществующий ID: 404, `{"detail":"Мероприятие не найдено"}`. Нецелый ID, неизвестная категория и превышение длины q: 422; штатный FastAPI возвращает detail с массивом описаний ошибок. Клиент не должен зависеть от точного текста ошибки.

## Event: обязательная проверка

Все поля обязательны, null запрещён. Типы проверяются строго: bool не является допустимым integer; строковые числа не преобразуются автоматически.

| Поля | Тип и ограничения |
| --- | --- |
| id | integer > 0 |
| title, venue, address, organizer, description | string, непустые после удаления крайних пробелов |
| category | string: concert / theatre / exhibition |
| starts_at | string, реальная дата/время ISO 8601 с часовым смещением |
| price | integer >= 0; 0 — бесплатное событие |
| currency | string, RUB |
| age_limit | string: 0+, 6+, 12+, 16+ или 18+ |
| url | string, относительный путь `/events/{id}`, соответствующий ID записи |
| theme | string, непустая цветовая тема |
| poster_title, poster_subtitle | string, непустые надписи постера |

Полный пример объекта и ответа списка — внутри `fixtures/200_detail.json` и `fixtures/200_list.json`, в поле body_text. После декодирования body_text получается именно тело API-ответа.

## Учебные маршруты

| GET | Поведение |
| --- | --- |
| /health | 200, {"status":"ok"} |
| /demo/500 | Всегда 500, JSON ошибки |
| /demo/rate-limited | Всегда 429, Retry-After: 2 |
| /demo/timeout?seconds=5 | Ответ через 5 секунд, 200 {"status":"ok"}; seconds от 0 до 30 |
| /demo/broken-json | 200 и application/json, тело `{"items": [` |
| /demo/bad-schema | 200, {"items":[{"name":"Концерт без обязательных полей"}],"count":1} |

/demo/500 и /demo/rate-limited не становятся успешными после повторов. Последовательности со сменой ответа задаются подменой транспорта в тестах. Маршрута, специально возвращающего 400, в основном сервисе нет: используйте fixture 400.json. Поведение HTTP-ошибок не зависит от того, валидно ли JSON-тело: сначала проверяется статус.

HTML-каталог `/` принимает те же фильтры; страницы `/events/{id}` имеют серверную разметку. Динамический бонус доступен по `/static/dynamic.html`; там карточки добавляет JavaScript, использующий этот же API.
